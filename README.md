# FormaLiving

A responsive, static landing page for **Furniture & Interiors**.

## Project structure

```text
.
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    │   └── products/
    ├── icons/
    └── fonts/
```

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Customisation

- Update the copy, navigation, contact address, and metadata in `index.html`.
- Change colours, spacing, and responsive rules in `style.css`.
- Add lightweight interactions in `script.js`.
- Store project-specific imagery under `assets/images/products/`, icons under `assets/icons/`, and licensed font files under `assets/fonts/`.
- Replace the illustrative CSS hero artwork with real, optimised images when brand-approved assets are available.

## Deployment

This site can be hosted by GitHub Pages or any static hosting provider. For GitHub Pages, select the intended branch and root folder in the repository's Pages settings.

## Notes

This is a front-end starter. Contact links use email and no backend or appointment, reservation, or enquiry processing is configured.
